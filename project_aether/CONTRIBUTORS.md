## あなたも貢献しませんか？

Project AETHER では、いつでも新しい貢献者を歓迎しています！

### 始め方
1. [CONTRIBUTING.md](CONTRIBUTING.md) を読む
2. 最初の Issue を見つける
3. Fork してブランチを作成
4. 変更を加えて PR を作成

### 必要なスキル
- ✅ 数学が好きな人
- ✅ 暗号に興味がある人
- ✅ AI を学びたい人
- ✅ 美しい UI を作りたい人
- ✅ ドキュメントを書ける人
- ✅ テストを書ける人
- ✅ バグを見つけて報告できる人

### 報酬
- 🎖️ 貢献者バッジ
- 📜 認定書（希望者のみ）
- 🌟 GitHub プロフィールでの称賛
- 💰 バグバウンティ（該当する場合）
- 🎁 限定グッズ（年間貢献者）
