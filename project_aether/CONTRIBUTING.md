# Contributing to Project AETHER

Project AETHER への貢献を歓迎します！このドキュメントでは、貢献の方法とガイドラインを説明します。

## 🌟 貢献の種類

### 1. コードの貢献

#### バグ修正
- 問題を見つけたら、まず Issue で報告してください
- 可能であれば修正を含む Pull Request を作成してください
- テストケースを追加して、修正が正しいことを証明してください

#### 新機能の実装
- まず Issue で機能提案を行ってください
- コアメンテナーの承認を得てから実装を開始してください
- 数学的証明が必要な場合は、証明も含めて提出してください

#### パフォーマンス改善
- ベンチマーク結果を含めて提出してください
- 滑らかさ指数 (C∞) が低下しないことを確認してください
- 美しさスコア (10.0/10.0) が維持されることを確認してください

### 2. ドキュメントの改善

- README の誤字脱字修正
- 使用例の追加
- 翻訳の提供（日本語・英語以外も歓迎）
- チュートリアルの作成

### 3. 数学的貢献

- 新しい数学的証明の提供
- アルゴリズムの最適化
- 量子耐性アルゴリズムの研究

### 4. テスト・品質保証

- ユニットテストの追加
- 統合テストの作成
- セキュリティ監査
- 量子耐性テスト

## 🚀 開発セットアップ

### 前提条件

- Python 3.9+
- Node.js 18+ (フロントエンド開発の場合)
- Git

### セットアップ手順

```bash
# リポジトリのクローン
git clone https://github.com/aether-project/project_aether.git
cd project_aether

# 仮想環境の作成（推奨）
python3 -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate

# 依存関係のインストール
pip install -r requirements.txt
pip install -r requirements-dev.txt

# 事前コミットフックのインストール
pre-commit install
```

## 📝 Pull Request の作成

### PR チェックリスト

- [ ] コード規約に従っている
- [ ] テストがパスしている
- [ ] ドキュメントを更新した
- [ ] 変更ログを追加した
- [ ] 数学的証明が必要な場合は証明を含めた
- [ ] 美しさスコアが維持されている
- [ ] 滑らかさ指数が低下していない

### PR テンプレート

```markdown
## 概要
<!-- 変更の概要を簡潔に説明 -->

## 変更内容
<!-- 具体的な変更内容を箇条書きで -->

## 数学的証明（該当する場合）
<!-- 数学的変更の場合は証明を提供 -->

## テスト結果
<!-- テスト結果を記載 -->

## チェックリスト
- [ ] コード規約遵守
- [ ] テストパス
- [ ] ドキュメント更新
- [ ] 美しさスコア維持 (10.0/10.0)
- [ ] 滑らかさ指数維持 (C∞)
```

## 🎨 コーディング規約

### Python コード規約

- PEP 8 に準拠
- 型ヒントを積極的に使用
- ドキュメント文字列を必須とする
- 数学関数には必ず証明または出典を記載

```python
def riemann_zeta_function(s: complex, terms: int = 1000) -> complex:
    """
    リーマンゼータ関数を計算する。
    
    ζ(s) = Σ(1/n^s) for n=1 to ∞
    
    Args:
        s: 複素数入力
        terms: 計算に使用する項数
    
    Returns:
        ゼータ関数の値
    
    Proof:
        オイラーの級数展開による。
        収束性は Re(s) > 1 で保証される。
    """
```

### JavaScript コード規約

- ESLint 設定に従う
- JSDoc コメントを必須とする
- 非同期処理は async/await を使用

## 🧪 テスト

### テストの実行

```bash
# 全テストの実行
pytest

# カバレッジレポート
pytest --cov=core --cov-report=html

# 美しさテスト
python tests/beauty_test.py

# 滑らかさテスト
python tests/smoothness_test.py
```

### テストのカバレッジ目標

- コアエンジン: 95% 以上
- 暗号モジュール: 100%
- 数学モジュール: 98% 以上
- フロントエンド: 90% 以上

## 🔒 セキュリティ

### セキュリティ報告

セキュリティ脆弱性を発見した場合は、公開 Issue ではなく、
security@project-aether.dev にメールしてください。

### 量子耐性テスト

全ての暗号実装は以下のテストに合格する必要があります：

1. NIST 量子耐性暗号標準テスト
2. 格子基底攻撃耐性テスト
3. ハイブリッド暗号整合性テスト

## 📊 レビュープロセス

1. **自動チェック**: CI/CD パイプラインが実行
2. **コードレビュー**: 最低 2 人のメンテナーがレビュー
3. **数学的検証**: 数学的変更は専門家によって検証
4. **美しさチェック**: UI 変更は美的スコアを維持
5. **マージ**: 全てのチェックがパスしたらマージ

## 🏆 貢献者特典

- 10 以上の PR マージ: AETHER Contributor バッジ
- 50 以上の PR マージ: AETHER Core Contributor バッジ
- 重要な機能実装: AETHER Fellow タイトル

## ❓ よくある質問

**Q: 数学が苦手でも貢献できますか？**  
A: はい！ドキュメント、テスト、UI など、数学がなくても貢献できる分野はたくさんあります。

**Q: 量子コンピューターの専門知識が必要ですか？**  
A: 基本的な理解は役立ちますが、必須ではありません。学習中の貢献も歓迎します。

**Q: 美しさスコアはどう測定されますか？**  
A: 黄金比準拠率、フラクタル次元、ユーザー評価などを総合的に評価します。
