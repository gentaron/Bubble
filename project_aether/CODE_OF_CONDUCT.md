# AETHER Project Code of Conduct

## 我々の誓い

Project AETHER は、全ての参加者に対して開かれた安全な環境を提供することを約束します。

### 我々の価値観

1. **数学的純度の尊重**
   - アーベル賞クラスの数学的厳密さを追求します
   - 証明と検証を重視します

2. **多様性の受容**
   - 国籍、人種、性別、宗教に関係なく歓迎します
   - 多様な視点がより良い数学と技術を生むと信じます

3. **量子耐性の精神**
   - 将来の変化にも耐えうる堅牢なコミュニティを目指します
   - 長期的視点で行動します

4. **ニューロシンボリックな協調**
   - 直感的理解と論理的思考の両方を尊重します
   - 異なるアプローチを統合します

### 期待される行動

- 他の参加者を尊重し、配慮ある言動をとる
- 建設的な批判を受け入れ、成長の機会とする
- コミュニティ全体の利益を個人の利益よりも優先する
- 誤りを認めて学び、改善する

### 許容されない行動

- 差別的・嫌がらせ的な発言や行為
- 他者の貢献を不当に貶める行為
- 無断での他者のコード・アイデアの流用
- コミュニティの和を乱す行為

### 報告手順

問題が発生した場合は、以下に連絡してください：
- メール: conduct@project-aether.dev
- 報告フォーム: https://project-aether.dev/report

全ての報告は秘密厳守で扱われ、72 時間以内に対応いたします。

### 施行

コミュニティガイドラインに違反した場合、以下の措置が取られる可能性があります：

1. 警告
2. 一時的なアクセス制限
3. 永久追放
