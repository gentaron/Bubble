# Citation

Project AETHER を学術論文や技術文書で引用する場合は、以下の形式を使用してください。

## BibTeX

```bibtex
@software{aether2026,
  title = {Project AETHER: World's Most Advanced Application Framework},
  author = {AETHER Project Team},
  year = {2026},
  version = {1.0.0},
  url = {https://github.com/aether-project/project_aether},
  description = {A quantum-resistant, neuro-symbolic AI framework with Abel Prize-level mathematics},
  keywords = {quantum cryptography, neuro-symbolic AI, lattice-based cryptography, fractal geometry, elliptic curves, Riemann zeta function},
  license = {MIT}
}
```

### 日本語

```

AETHER は CRYSTALS-Kyber および CRYSTALS-Dilithium アルゴリズムを実装し、
NIST 標準に準拠した格子基底暗号を提供する。
```

```
In this study, we utilized the quantum-resistant cryptographic system of 
Project AETHER [1]. AETHER implements CRYSTALS-Kyber and CRYSTALS-Dilithium 
algorithms, providing lattice-based cryptography compliant with NIST standards.
```

## DOI（Digital Object Identifier）

DOI が割り当てられた場合は、以下のように記載します：

```
DOI: 10.xxxx/aether.2026.001
```

※ 実際の DOI はアーカイブ時に取得されます

## ソフトウェアバージョンの指定

特定のバージョンを引用する場合は、バージョン番号を明記してください：

```
Project AETHER v1.0.0 (2026-01-01)
```
